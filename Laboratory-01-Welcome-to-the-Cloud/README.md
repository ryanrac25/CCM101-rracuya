# Mission 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the basic working environment of a cloud infrastructure engineer. The activity focused on using a cloud-based Linux environment through KillerCoda, exploring Linux commands, gathering system information, organizing files, and creating a professional GitHub portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed an Ubuntu Linux environment through KillerCoda.
2. Created a new Linux user with sudo privileges.
3. Logged in using the newly created user account.
4. Gathered basic system information.
5. Created and organized files and directories.
6. Created a GitHub repository for the Cloud Computing portfolio.
7. Documented the laboratory activity using Markdown.
8. Captured screenshots as evidence of completed activities.

## Skills Learned

Through this activity, I learned how to access and work inside a cloud-based Linux environment, manage Linux users, navigate the Linux file system, gather system information, organize files, and document technical work using Markdown and GitHub.
