# Mission 1 Reflection

This laboratory activity gave me my first hands-on experience working inside a cloud-based Linux environment. Using KillerCoda allowed me to access an Ubuntu environment through a web browser without installing a complete Linux operating system on my computer.

One of the most important things I learned was how to navigate and manage a Linux environment using commands. I learned how to identify the current user, working directory, and hostname. I also learned how to create a Linux user, assign sudo privileges, and log in using the newly created account.

I also practiced gathering system information such as the Linux distribution, kernel version, CPU information, memory, and available disk space. These are important information that a cloud infrastructure engineer needs when managing servers and cloud environments.

Another important part of the activity was organizing files and directories. Creating folders and Markdown files helped me understand the importance of maintaining an organized workspace. I also learned how Markdown can be used to document technical activities in a clear and professional way.

Finally, creating a GitHub portfolio introduced me to the importance of version control and documentation. GitHub provides a central location where I can store my laboratory activities, track my work, and build a portfolio of my technical skills.

Overall, Mission 1 helped me understand the basic responsibilities of a cloud infrastructure engineer and gave me practical experience with Linux, documentation, Git, and GitHub.
