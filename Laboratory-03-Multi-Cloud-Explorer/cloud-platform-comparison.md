## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS is generally considered to offer one of the broadest selections of cloud services among the major public cloud providers. Its service portfolio covers computing, storage, networking, databases, security, analytics, artificial intelligence, machine learning, and many other technologies.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies because it is part of the Microsoft ecosystem. It works closely with technologies such as Windows Server, Microsoft 365, and Microsoft identity solutions, making it a strong choice for organizations that already depend heavily on Microsoft products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes technologies. Google Kubernetes Engine (GKE) provides a managed Kubernetes environment, while Google Cloud also offers a broad set of AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Amazon Web Services because it provides a broad range of cloud services and gives organizations many options for building and scaling applications. AWS also provides services for computing, storage, networking, security, databases, analytics, and other cloud requirements, making it a flexible platform for different types of projects.
